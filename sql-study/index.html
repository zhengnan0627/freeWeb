SQL 学习目录

按阶段学习：先建立概念，再理解表结构、练习数据操作，最后逐步掌握真实全栈项目中的查询能力。

阶段一

数据库基础概念

用 Excel 类比理解数据库、表、字段、记录，以及建库到查询的整体流程。

 阶段二

表结构和建表语句

理解 users 表、字段类型、主键、自增、默认值和 SQL 关键字顺序。

 阶段三

数据增删改查

学习 INSERT、SELECT、WHERE、UPDATE、DELETE，以及 WHERE 的安全边界。

 阶段四

全栈开发思维

把前端页面中的列表、详情、编辑、删除，对应到数据库表和 SQL 操作。

 阶段五

列表查询进阶

学习排序、多条件筛选、模糊搜索、分页、总数统计和分组统计。

 阶段六

表关系和 JOIN 联表

理解一对多关系、外键字段，以及如何把用户表和文章表一起查询。

 阶段七

多对多关系和关联表

用用户、角色、用户角色关联表，理解真实权限系统里的多对多关系。

 阶段八

SQL 书写顺序和逻辑处理顺序

理解 SQL 为什么不是从 SELECT 开始处理，以及各个关键字真正的解析顺序。

 阶段九

约束和数据可靠性

学习 NOT NULL、UNIQUE、DEFAULT、CHECK、FOREIGN KEY，让数据库帮你拦住脏数据。

 阶段十

索引和查询性能

理解索引为什么能加速查询、什么时候该建索引，以及索引为什么不是越多越好。

 阶段十一

事务和数据一致性

学习 START TRANSACTION、COMMIT、ROLLBACK，理解转账和下单为什么需要事务。

 阶段十二

锁和并发控制

理解多人同时修改同一份数据为什么会出错，以及数据库如何用锁保护余额、库存这类关键数据。

 阶段十三

后端如何使用数据库

理解 Node.js 后端如何连接 MySQL、执行参数化查询、返回安全字段，并在代码里使用事务。
