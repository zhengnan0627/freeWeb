列表查询进阶

这一阶段学习后台列表页最常见的查询能力：筛选、搜索、排序、分页和统计。

一、先准备几条练习数据

为了能看到筛选、排序和分页效果，可以先让 users 表里有多条不同的数据。

-- 一次插入多条练习数据，方便后面测试排序、筛选和分页
INSERT INTO users (username, age) VALUES
  ('lisi', 22),
  ('wangwu', 16),
  ('zhaoliu', 30),
  ('xiaoming', 22),
  ('xiaohong', 19);
这段写法和以前有什么不同

以前一次只插入一条数据；这里在一个 VALUES 后面写了多组值，因此可以一次插入多条记录。

二、ORDER BY 排序

升序 ASC

从小到大排序。ASC 是默认顺序，可以省略。

-- 按年龄升序排序：年龄小的排在前面
SELECT id, username, age
FROM users
ORDER BY age ASC;

降序 DESC

从大到小排序。查询最新创建的数据时经常使用。

-- 按年龄降序排序：年龄大的排在前面
SELECT id, username, age
FROM users
ORDER BY age DESC;
Excel 类比：ORDER BY 就像对某一列进行升序或降序排列。

三、使用 AND 组合多个条件

AND 表示多个条件必须同时满足。下面只查询年龄大于等于 18，并且小于等于 25 的用户。

-- 查询年龄在 18 到 25 之间的用户
SELECT id, username, age
FROM users
WHERE age >= 18
  AND age <= 25;

AND：同时满足

条件 A 和条件 B 都成立，记录才会被查询出来。

OR：满足一个即可

条件 A 或条件 B 任意一个成立，记录就会被查询出来。

-- 查询年龄等于 18 或者等于 22 的用户
SELECT id, username, age
FROM users
WHERE age = 18 OR age = 22;
注意：同时使用 AND 和 OR 时，建议使用括号明确组合关系，避免条件和你想的不一样。

四、LIKE 模糊搜索

条件含义可能匹配
LIKE 'xiao%'以 xiao 开头xiaoming、xiaohong
LIKE '%ming'以 ming 结尾xiaoming
LIKE '%xiao%'任意位置包含 xiaoxiaoming、xiaohong

后台列表中的搜索框，常常会对应一个模糊查询条件。

-- 模糊搜索：查询用户名中包含 xiao 的用户
SELECT id, username, age
FROM users
WHERE username LIKE '%xiao%';

五、LIMIT 分页查询

只查询前 3 条

-- 分页第一页：按照 id 升序，只查询前 3 条
SELECT id, username, age
FROM users
ORDER BY id ASC
LIMIT 3;

跳过 3 条，再查询 3 条

-- 分页第二页：跳过前 3 条，再查询 3 条
SELECT id, username, age
FROM users
ORDER BY id ASC
LIMIT 3 OFFSET 3;
前端分页类比：第一页查询前 3 条；第二页先跳过前 3 条，再查询接下来的 3 条。

六、COUNT 统计总数

统计所有用户数量

-- 统计 users 表中一共有多少条用户记录
SELECT COUNT(*) AS total
FROM users;

统计成年用户数量

-- 统计年龄大于等于 18 的用户数量
SELECT COUNT(*) AS adult_total
FROM users
WHERE age >= 18;
AS 是什么：AS total 是给查询结果起一个更容易理解的名字。前端分页组件显示的总条数，通常来自 COUNT。

七、GROUP BY 分组统计

下面会按照年龄分组，然后统计每个年龄分别有多少用户。

-- 按年龄分组，统计每个年龄分别有多少用户
SELECT age, COUNT(*) AS user_total
FROM users
GROUP BY age
ORDER BY age ASC;
Excel 类比：GROUP BY 很像数据透视表，先按某一列分组，再对每组做统计。

八、把列表查询组合起来

下面模拟一个用户列表接口：搜索用户名中包含 xiao 的成年用户，按创建时间倒序，只返回前 10 条。

-- 模拟后台用户列表查询：搜索、筛选、排序、限制返回条数
SELECT id, username, age, created_at
FROM users
WHERE username LIKE '%xiao%'
  AND age >= 18
ORDER BY created_at DESC
LIMIT 10;
按顺序理解

SELECT：决定返回哪些字段。

FROM：决定从哪张表查询。

WHERE：筛选符合条件的记录。

ORDER BY：给筛选结果排序。

LIMIT：限制最终返回多少条。
