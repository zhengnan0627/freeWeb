表结构和建表语句

这一阶段重点理解 users 表怎么设计，以及字段名、类型、约束、自增主键分别是什么意思。

一、第一张 users 表

字段类型约束含义
idINTPRIMARY KEY、AUTO_INCREMENT用户唯一编号，自动递增。
usernameVARCHAR(50)NOT NULL最多 50 个字符，并且不能为空。
ageINT无整数，可以为空。

二、建表 SQL 怎么读

-- 创建 users 用户表
CREATE TABLE users (
  -- id 是主键，会自动生成 1、2、3...
  id INT PRIMARY KEY AUTO_INCREMENT,
  -- username 是用户名，不能为空，最多 50 个字符
  username VARCHAR(50) NOT NULL,
  -- age 是年龄，可以为空
  age INT,
  -- created_at 是创建时间，不传值时默认当前时间
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP
);
逐行解释

CREATE TABLE users：创建一张名为 users 的表。

id INT PRIMARY KEY AUTO_INCREMENT：id 是整数主键，并且自动递增。

username VARCHAR(50) NOT NULL：用户名最多 50 个字符，不能为空。

age INT：年龄是整数，可以为空。

created_at DATETIME DEFAULT CURRENT_TIMESTAMP：创建时间默认使用当前时间。

三、id、主键和自增

不写 id 就没有 id

数据库不会默认给表添加 id。你在建表时设计了这个字段，表里才会有。

-- 字段定义片段：放在 CREATE TABLE 的括号里面使用
id INT PRIMARY KEY AUTO_INCREMENT

三层含义

id 是字段名，INT 是整数类型，后面的关键字表示它是自动递增的主键。

通常只有一个

一张表可以有很多普通字段，但通常只需要一个自增主键来唯一标识每一行。

名字可以改变

它也可以叫 user_id，只是很多项目会统一使用 id。

-- 字段定义片段：字段名也可以叫 user_id
user_id INT PRIMARY KEY AUTO_INCREMENT
Excel 类比：id 就像你主动增加的“唯一编号”列。你不加，它就不存在。

四、SQL 关键字顺序

查询语句

-- 查询用户 id 和用户名，并按创建时间倒序排列
SELECT id, username
FROM users
WHERE age > 18
ORDER BY created_at DESC;

常见顺序

先写 SELECT，再写 FROM，然后是 WHERE，最后是 ORDER BY。

字段定义

推荐按“字段名、字段类型、字段约束”的顺序书写。

-- 字段定义片段：推荐按字段名、类型、约束的顺序写
id INT PRIMARY KEY AUTO_INCREMENT

少数规则可以换

某些约束的顺序可能都能执行，但入门阶段固定一种标准写法更容易阅读和排错。
