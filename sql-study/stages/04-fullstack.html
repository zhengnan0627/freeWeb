全栈开发思维

把你熟悉的前端页面动作，映射到后端接口、数据库表和 SQL 操作上。

一、前端页面和数据库的对应关系

前端视角数据库视角例子
用户列表数据库里需要用户表users
展示用户名、年龄和时间表中需要对应字段username、age、created_at
打开用户详情通过唯一 id 查询一行WHERE id = 1
编辑用户修改指定记录UPDATE 配合 WHERE
删除用户删除指定记录DELETE 配合 WHERE

二、阶段练习目标

能说清楚数据库、表、字段、记录分别是什么。
能看懂简单用户表中每个字段的类型和约束。
能解释为什么 id 通常要作为主键，以及不写 id 会发生什么。
能说出 INSERT、SELECT、UPDATE、DELETE 分别对应什么操作。
知道 WHERE 在查询、修改和删除中的作用。
知道修改和删除前为什么应该先查询确认。
