数据增删改查

这一阶段开始进入真实操作：新增、查询、条件筛选、修改和删除。

一、插入和查询

插入数据

先写要填哪些字段，再按相同顺序写对应的值。

-- 往 users 表新增一条用户数据
INSERT INTO users (username, age)
VALUES ('zhangsan', 18);
为什么没有写 id 和 created_at

id 会自动递增；created_at 有默认当前时间。

查询数据

SELECT 表示要取哪些字段，FROM 表示从哪张表取。

-- 查询 users 表中的指定字段
SELECT id, username, age, created_at
FROM users;
为什么不总是使用 SELECT *

明确字段更稳定，也可以减少不必要的数据返回。

二、CRUD 是什么

简称英文SQL页面中的操作
CCreateINSERT新增用户、文章或订单。
RReadSELECT列表、详情、搜索和筛选。
UUpdateUPDATE编辑资料、修改状态。
DDeleteDELETE删除或移除记录。

三、WHERE 条件查询

按年龄筛选

-- 查询年龄大于等于 18 的用户
SELECT id, username, age, created_at
FROM users
WHERE age >= 18;

按 id 查详情

-- 查询 id 等于 1 的用户
SELECT id, username, age, created_at
FROM users
WHERE id = 1;

按用户名精确查询

-- 查询用户名等于 zhangsan 的用户
SELECT id, username, age, created_at
FROM users
WHERE username = 'zhangsan';

模糊搜索

% 表示前后可以有任意内容。

-- 查询用户名中包含 zhang 的用户
SELECT id, username, age, created_at
FROM users
WHERE username LIKE '%zhang%';

四、WHERE 在 SELECT、UPDATE、DELETE 里的作用

语句 WHERE 的作用 不写 WHERE 的结果
SELECT 筛选要查询哪些数据。 查询整张表的所有记录。
UPDATE 限定要修改哪几行数据。 可能修改整张表的所有记录。
DELETE 限定要删除哪几行数据。 可能删除整张表的所有记录。

SELECT 里的 WHERE

查询时，WHERE 像 Excel 的筛选按钮。它决定“返回哪些行”，不会改变表里的数据。 

-- SELECT 中的 WHERE 只负责筛选查询结果
SELECT id, username, age
FROM users
WHERE age >= 18;

UPDATE 里的 WHERE

修改时，WHERE 决定“修改哪些行”。如果条件写错，可能会改错用户。 

-- UPDATE 中的 WHERE 决定修改哪一行
UPDATE users
SET age = 20
WHERE id = 1;

DELETE 里的 WHERE

删除时，WHERE 决定“删除哪些行”。新手阶段执行删除前，建议先用同样条件查一遍。 

-- 删除前先查一下，确认这就是要删除的数据
SELECT id, username, age
FROM users
WHERE id = 1;

-- 确认无误后，再删除 id 等于 1 的用户
DELETE FROM users
WHERE id = 1;

最常见的安全习惯

先写 SELECT 确认命中的数据，再把同一个 WHERE 条件用于 UPDATE 或 DELETE。 

-- 先用 SELECT 确认 WHERE 条件命中了哪些数据
SELECT id, username, age
FROM users
WHERE id = 1;
记住： SELECT 不写 WHERE 通常只是查得多；UPDATE 和 DELETE 不写 WHERE 就可能直接影响整张表。

五、UPDATE 修改数据

修改一个字段

-- 把 id 等于 1 的用户年龄改成 20
UPDATE users
SET age = 20
WHERE id = 1;

修改多个字段

-- 同时修改 id 等于 1 的用户名称和年龄
UPDATE users
SET username = 'lisi',
    age = 22
WHERE id = 1;
重要：如果 UPDATE 忘记写 WHERE，可能会把整张表的所有记录都修改掉。

六、DELETE 删除数据

先查询确认

-- 删除前先查询确认
SELECT id, username, age, created_at
FROM users
WHERE id = 1;

删除指定记录

-- 删除 id 等于 1 的用户
DELETE FROM users
WHERE id = 1;
重要：如果 DELETE 忘记写 WHERE，可能会删除整张表中的所有数据。
阶段目标：能说出 INSERT、SELECT、UPDATE、DELETE 分别做什么，并知道 WHERE 是修改和删除的安全边界。
